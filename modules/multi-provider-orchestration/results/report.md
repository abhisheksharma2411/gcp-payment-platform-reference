# multi-provider-orchestration results

Generated by `scripts/report.ts`. **Simulated result.** Deterministic:
no cloud project, no credentials, no network. Neither simulated provider
reproduces any real provider's API, codes or behaviour; they differ along
the dimensions the article argues a generic interface must not erase.

## What a lowest-common-denominator interface would have to erase

- methods: acquirer-a only [wallet], acquirer-b only [bank_transfer]
- currencies: acquirer-a only [GBP,USD], acquirer-b only [SEK]
- countries: acquirer-a only [FR,GB,US], acquirer-b only [SE]
- separateCapture: acquirer-a=true, acquirer-b=false
- honoursIdempotencyKey: acquirer-a=true, acquirer-b=false
- supportsQuery: acquirer-a=true, acquirer-b=false
- timeoutMs: acquirer-a=8000, acquirer-b=20000

Each line is a field a generic adapter would have to drop or flatten, and
each one changes what the caller may safely do.

## When failover is safe

| attempt outcome | failover |
|---|---|
| `NOT_SENT` | SAFE |
| `DECLINED` | ALLOWED_DECLINED |
| `AUTHORIZED` | BLOCKED_AUTHORIZED |
| `UNKNOWN` | BLOCKED_UNKNOWN |

Only `NOT_SENT` proves the provider has nothing recorded. Everything else
is a guess with somebody's money behind it.

## The double charge, with and without the guard

Twenty-five operations where the first provider times out **having already
authorised**. Each provider later reports its own side.

| unknown-outcome guard | attempts | blocked failovers | double authorizations |
|---|---:|---:|---:|
| in place | 25 | 3 | **0** |
| removed | 28 | 0 | **3** |

Removing one condition produced double authorizations. The count is **3**
rather than 25 because the circuit breaker opened after three failures and
moved the rest of the traffic to the healthy provider -- so the blast radius
here is the product of two guards, and only one of them was removed.

That is the more useful reading: the unknown-outcome guard prevents the
duplicate, and the circuit breaker bounds how many operations reach the
condition at all. Remove both and all 25 duplicate.

## The circuit under a flapping signal

Four failure-and-recovery cycles produced **12 state transitions**.
Hysteresis on close and a clock-driven half-open mean a provider that is
intermittently failing does not move all the traffic each time it stumbles.
