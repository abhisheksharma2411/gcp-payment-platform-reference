## The independence control

The ledger truncates every amount to whole currency units. Both legs move
together, so the ledger own balance invariant — which shares `signedMinor`
with the code that wrote the postings — reports no problem.

- `Ledger.isBalanced('op_cap_1')` → **true**
- seam auditor → **S11_POSTED_AMOUNT_MISMATCH**

The auditor compares the postings against the command that caused them.
The ledger has never seen a command, so it cannot make that comparison.
